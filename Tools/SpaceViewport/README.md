# 舷窗与凤凰轨道航行

Unity 工程：`E:\mygame\PhoenixRace`；编辑器：Unity 2022.3.35f1c1。
使用 PowerShell 7 执行 `build_bundle.ps1`，由统一入口导出特效和舷窗的 RimUnity 资源清单。流程不启动游戏或进入 Play Mode。

## 操作

底部「舰船」打开座舱。鼠标悬浮星球本体高亮，点击后经过约 0.6 秒进入球面导航。左键拖动旋转、滚轮在完整球体可见范围内缩放，点击地块锁定区域，再按「确认航行」。右侧显示当前位置、经纬度、生态区、目标及预计时间。「当前位置」对准舰船，「全球视图」恢复完整球体，「返回座舱」反向过渡。

航行中允许观察，不允许直接改道；「停止航行」停在当前位置，随后可重新选区。Esc 依次取消待确认目标、退出导航、关闭座舱。座舱打开后跳过原版 UIRoot_Play.UIRootOnGUI 方法体，底部主按钮、时间栏、提示和原版调试界面一起隐藏，同时保留 Root.OnGUI 的界面缩放与 RimUnity 在 UIRoot_Play 上的画布输入、绘制补丁；右上角「关闭舰船」或 Esc 关闭后恢复。UGUI 提供暂停和倍速按钮，也支持空格与 1/2/3 时间快捷键。

## 独立航行规则

- 凤凰舰船使用自己的持久位置，不依赖原版重力引擎，不搬迁殖民地，不执行原版起降、不消耗燃料。
- 首次打开以有效当前地图的径向方向初始化；没有地图时选择地块并点击「设为起始位置」。切换地图不会覆盖已有位置。
- 最短球面弧距离乘以每度 20 刻计算总时长，半圈航行 3600 刻，正常速度约一分钟；另计 180～900 刻的原地转向（正常速度 3～15 秒；小于一度无需转向）。转向期间模型绕径向旋转并侧倾，随后平滑起步，抵达时减速悬停。预计时间包含转向，按正常游戏速度显示。
- 航行由 GameComponentTick 推进，暂停则停止、加速则加快；关闭界面后继续。存档保存位置、航向、起终点、目标地块、经过刻数及总刻数。
- 球面虚线与船模、舷窗镜头读取同一份位置。相机位于地表半径的 1.065 倍，垂直视场 44 度，沿航向斜望星球边缘，弧形地平线靠近画面上缘；航行和悬停维持低轨道巨型地表构图。舷窗手动渲染期间使用奥德赛背景模式，显示原版云层、大气辉光与昼夜日照，隐藏地块选择网格；渲染完毕还原模式和全局光照参数。
- 地球只生成部分地表的存档中，未生成区域用深色完整球壳显示，不伪造海陆或地块；未生成区域不能作为目的地，航线可经过其上空。

## 资源与代码职责

`ArtSource/SpaceViewport/Hologram` 保存着色器；`ShipModel` 保存 MDL_Ship.fbx；`RedPedestalUI` 保存台座与半透明舷窗美术。

`PhoenixNavigationPrefabComposer` 生成 NavigationOverlay 下的背景遮罩、GlobeTarget、Controls、提示与状态，以及球面下的 HoverRegion、TargetRegion、Route。导出时将 Canvas 与 PhoenixHologramWorld 三维场景分别写入 RimUnity 清单，运行时共同实例化。

模组 `UI/SpaceViewport/Navigation` 按持久航行、球面数学、地块空间索引、选区路线、交互视图、舷窗相机和输入生命周期拆分。GameComponent_PhoenixSpaceViewport 只协调界面资源。运行时网格、相机、渲染纹理在退出当前游戏时释放，关闭窗口时停用视觉更新。

发布必须同时部署 `1.7/Assemblies/PhoenixRaceLib.dll` 与完整的 `1.7/Data/RimUnity` 目录。运行依赖 RimUnity、ChezhouLib 和 Humanoid Alien Races 的 1.7 版本。

`OpaqueCabinBackdrop` 在座舱最底层提供全屏不透明底色，半透明舷窗只透出星球画面。`OrbitPresentation` 材质忽略星球渲染纹理的透明度，以 1.3 倍曝光和 0.82 中间调指数提亮窗外地表，保留太空暗部和昼夜差异。镜头高度为星球半径的 6.5%，相比 10% 高度降低 35%；镜头沿航向向地平线抬起，以保留大气轮廓。显示材质使用实际镜头中的球心和视场计算地平线，叠加蓝色散射带，并仅在边缘进行 2.4 像素范围的柔化采样。大气厚度 0.018、强度 0.38，与曝光参数一起在 `PhoenixOrbitPresentationComposer` 中维护。每个座舱实例独占显示材质并随界面资源释放，不更改原版共享材质。需人工检查不同分辨率下的地平线、大气辉光、侧倾时边缘对齐，以及不再透出地图和生物。

## 验收边界

本次仅执行代码编译、Unity Shader/AB 构建及静态资源核对，未启动游戏或 Play Mode。

待人工检查：正圆北朝上球体；悬浮与空白区区分；进出过渡；不同分辨率和 UI 缩放的拖动/点击/拾取；背面与两极；虚线背面遮挡；同位置拒绝、短途/半圈/对跖点航线；停止与抵达；暂停/加速；关闭界面继续航行；航行中存读档；切换地图不重置位置；舷窗大陆和地平线随航程连续变化；返回主菜单无残留。

座舱镜头与导航裁切修订仅执行程序集编译、AB 构建及部署核对；需人工检查窗外星球、原地转向、抵达悬停、导航完整边缘及隐藏/恢复 IMGUI。

舰船模型负长轴的舰艏在构建时统一到正 Z、厚度轴统一到正 Y。ShipLocation 负责球面定位，ShipHeading 负责舰体与金色舰艏箭头的朝向和倾斜；定位环不随偏航旋转。预计航程包含每秒约十二度的转向时间，暂停及倍速规则不变。模型朝向、窗外云层、大气辉光和昼夜构图仅完成编译及资源构建，仍需游戏内人工确认。
